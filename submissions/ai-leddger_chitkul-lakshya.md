# Project Submission: ai.leddger

## Project Details

- **Project Name:** ai.leddger
- **Your Name:** Chitkul Lakshya
- **Problem Statement Selected:** HR Cost Intelligence & Meeting Analytics (Tracking and analyzing meeting overhead costs)
- **Project Description:** An AI-powered SaaS dashboard and API platform designed to track, audit, and analyze the human resource cost associated with calendar meetings.
- **Approach:** We built a responsive dark-mode React dashboard with a FastAPI backend that integrates with the Google Calendar API and uses Gemini 1.5 Flash (with heuristic fallback) to automatically classify meetings into projects.
- **Tools and Technologies Used:** React 19, Vite, Vanilla CSS, Recharts, Firebase Client SDK (OAuth), Python, FastAPI, Uvicorn, google-api-python-client (Calendar API), Google Generative AI SDK (Gemini 1.5 Flash).

## What Makes a Good Submission?

- **What problem you selected:** We selected the problem of tracking and analyzing hidden corporate costs associated with meeting overheads.
- **What your project does:** It pulls calendar meetings via Google API and automatically attributes their estimated resource cost to projects.
- **Why your solution is useful:** It gives organization leaders and project managers transparent financial insights into calendar resource distribution.
- **How you approached the problem:** We created a high-fidelity React dashboard and a FastAPI backend classifying meetings via AI and keyword matching.
- **What AI tools or technologies you used:** We used Google's Gemini 1.5 Flash API for automated cost attribution and project tagging.
- **What is already working:** Landing page, Google login (Firebase Auth), calendar event fetch, and AI cost classification are fully working.
- **What you plan to improve next:** Inspired by our collaborative project **Zync**, we want to bring its real-time CRDT notes and Kanban task-sync features directly into `ai.leddger` so teams can immediately turn meeting cost insights into actionable project tasks.
